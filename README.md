# -E-Commerce-Shipping-Delivery-Dashboard
## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze e-commerce shipping performance. It helps operations teams track delivery delays, shipment modes, and warehouse efficiency.

## 🛠️ Tools Used
* **Power BI Desktop** (Data Visualization, Power Query)
* **CSV Dataset** (10,999 records)

## 📊 Dashboard Features
* **Modern UI:** Classic dark charcoal background with clean white KPI cards and light gray borders.
* **Data Transformation:** Used Power Query to replace binary values (1/0) in the "Delivery Status" column for better readability.
* **KPI Cards:** Total Orders, Average Customer Rating, and Average Product Cost.
* **Dynamic Slicer:** Filter the entire dashboard by Warehouse Block (A, B, C, D, F).
* **Visualizations:** 
  - Delivery Status (Donut Chart)
  - Orders by Shipment Mode (Bar Chart)
  - Orders by Warehouse Block (Column Chart)
  - Product Importance Split (Pie Chart)

## 💡 Key Insights
* Warehouse F handles the highest volume of shipments.
* "Ship" is the most used mode of shipment, followed by Flight and Road.
* Medium product importance makes up the largest portion of orders.
